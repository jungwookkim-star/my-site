업무 연락, 회원가입 인증, 중고거래 연락까지 **개인 번호 하나로 다 받다 보면** 불편한 일이 생깁니다. 그렇다고 번호를 새로 바꾸기는 부담스럽죠. 이럴 때 쓰는 방법이 **세컨드 번호**입니다. 쓰던 번호와 통신사는 그대로 두고 번호만 하나 더 만드는 방식이에요.

## 1. 세컨드 번호는 이런 때 써요
| 상황 | 이유 |
|---|---|
| 업무용 | 거래처나 고객 연락을 개인 번호와 나누고 싶을 때 |
| 인증용 | 회원가입이나 본인 확인에 쓰는 번호를 따로 두고 싶을 때 |
| 중고거래·택배용 | 개인 번호를 알려주기 부담스러울 때 |
| 계정 분리 | 본계정과 부계정을 따로 쓰고 싶을 때 |

앤텔레콤 공식 안내도 업무·개인용, 본계정·부계정, 택배·중고거래용 등으로 "한 폰 두 번호" 활용을 소개합니다.

## 2. 만드는 방법은 세 가지
**① eSIM으로 추가하기 (유심 없이)**
- 쓰던 번호는 실물 유심으로 그대로 두고, 두 번째 번호를 eSIM으로 추가합니다.
- 한 휴대폰에서 번호 두 개를 동시에 쓸 수 있고, 유심을 사러 갈 필요가 없어요.
- 선불 eSIM은 **LG망(L망)** 에서만 개통됩니다. 발급비는 2,750원입니다.

**② 공기계에 유심 끼우기**
- 쓰던 공기계에 선불 유심을 끼워 두 번째 폰으로 씁니다.
- KT망과 LG망 중에서 고를 수 있고, 유심비는 8,800원입니다.

**③ 유심 바꿔 끼우기**
- 하나의 휴대폰에서 유심을 번갈아 끼우는 방법인데, 번호가 동시에 켜지지 않아 업무용이나 인증용으로는 불편합니다.

## 3. 내 휴대폰이 eSIM이 되는지 확인하기
앤텔레콤 안내 기준으로 **아이폰 XS 이후, 갤럭시 Z Flip4·Z Fold4 이후와 해외 eSIM 지원 기종**에서 쓸 수 있습니다. 가장 쉬운 확인법은 전화 앱 키패드에서 **\*#06#** 을 누르는 것입니다. 화면에 EID와 IMEI 번호가 나오면 eSIM 개통이 가능해요.

통신사 약정으로 산 휴대폰은 eSIM 조회가 안 될 수 있어요. 그때는 실물 유심으로 진행하세요.

## 4. 얼마나 드나요?
| 용도 | 요금제 | 월 요금 |
|---|---|---|
| 인증, 문자 수신 | 선불 기본1 | 12,100원 |
| 가벼운 메신저와 검색 | L망 선불 데이터 2.5GB | 17,000원 |
| 업무 통화가 많은 번호 | L망 선불 300분 | 20,800원 |
| 폰처럼 쓰는 번호 | 선불 396 (10.3GB) | 39,600원 |

요금제 정보는 앤텔레콤 공식 기준이고, 선불은 **개통한 날 충전**이 필요합니다. 충전하지 않으면 번호가 정지되거나 해지될 수 있어요. [요금제 전체 비교](/plans/)에서 확인하세요.

## 5. 시작하기 전 확인할 것
- 셀프개통은 **만 19세 이상 내국인**이 간편인증과 신분증으로 진행합니다. 외국인과 미성년자는 [방문 개통 예약](/blog/visit-activation-reservation/)을 이용하세요.
- 신규가입은 08:00~21:50에 접수할 수 있습니다.
- 모든 번호는 **본인 명의**로 개통합니다.
- eSIM 접수 순서는 [eSIM 개통 방법](/blog/esim-vs-usim/) 글을 참고하세요.
