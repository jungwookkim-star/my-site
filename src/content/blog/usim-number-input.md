셀프개통 중간에 나오는 **단말 등록** 화면에서는 유심의 모델코드와 번호를 입력해야 합니다. 처음 보면 어디에서 확인하는지 헷갈리기 쉬워서, 화면 순서대로 정리했습니다.

## 1. 단말 등록 화면에서 하는 일
화면에서는 아래 항목을 선택하거나 입력합니다.

| 항목 | 설명 |
|---|---|
| 유심개통여부 | 이미 가진 유심은 "직접등록", 유심이 없으면 "구매요청" |
| USIM모델코드 | 화면의 선택지(K9000, K3600)를 고르거나 "직접입력" 선택 후 5자리 입력 |
| USIM번호 | 유심 포장 또는 카드 뒷면의 번호 |
| 유심수납방법 | 화면의 기본 선택 그대로 진행 |

모델코드 입력칸에는 "5자리"라고 안내되어 있습니다.

## 2. 번호는 유심 뒷면에서 찾아요
- 유심 카드 뒷면(또는 바코드 근처)에 **모델코드**와 **유심번호**가 함께 인쇄되어 있습니다.
- KT 유심은 유심번호를 **숫자 19자리**로 입력합니다.
- LG 모두의 유심 원칩 같은 LG망 전용 유심은 카드에 **"유심정보"로 표시된 8자리**를 확인해서 입력합니다.
- 유심을 카드에서 **뜯기 전에** 번호 부분을 사진으로 찍어 두면, 입력할 때 다시 확인하기 편합니다.
- 번호를 입력할 때는 숫자만 입력하고, 띄어쓰기나 기호는 넣지 않는 것이 안전합니다.

## 3. 입력 전에 한 번 더 확인하세요
- 구매한 유심이 **선택한 통신망(KT 또는 LG)과 같은지** 포장의 상품명으로 확인하세요. 다르면 접수를 처음부터 다시 해야 할 수 있습니다.
- 숫자가 흐리게 보이면 밝은 곳에서 사진을 찍어 확대해서 보면 편합니다.

## 4. 헷갈리면 사진으로 문의하세요
카드에서 어느 쪽이 모델코드이고 어느 쪽이 번호인지 헷갈린다면, **유심 뒷면 사진**을 카카오톡으로 보내 주세요. 사진으로 확인해서 입력할 값을 안내해 드립니다. 다만 사진에 보이는 유심번호는 개인 정보이니 다른 곳에는 올리지 마세요.
